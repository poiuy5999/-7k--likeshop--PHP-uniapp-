Likeshop 最新版连锁点餐系统，后端采用 PHP 开发，前端基于 UniApp 全开源开发，一套前端代码可编译微信、支付宝小程序、H5，面向连锁餐饮门店，兼顾堂食扫码点餐、外卖配送、到店自提，实现总部统一管控、门店独立运营。

系统架构分为平台总后台、门店管理后台、用户端三端。总后台负责门店新增、全局菜品库管理、统一营销配置、权限分配、全连锁经营数据统计，支持总部统一上架菜品，门店可单独调价、上下架。门店后台独立管理本店桌台、菜品库存、订单接单、小票打印，单独设置配送范围、起送价、配送费，自主配置门店活动。

顾客端支持桌码扫码堂食点餐、外卖下单、购物车、在线支付、优惠券、会员储值、订单查询。UniApp 跨端特性，覆盖小程序与 H5 多渠道引流，适配中餐、奶茶、生鲜等业态。系统内置套餐、满减、积分等营销模块，可扩展收银台、存酒、订单代付功能，打通线上线下收银场景。

项目代码完全开源无加密，PHP 后端基于成熟框架，代码结构清晰，便于二次开发。数据库采用多租户设计，通过 store_id 实现门店逻辑数据隔离，保障各门店订单、会员数据互不干扰，总部统一汇总统计。权限基于 RBAC 模型，区分平台管理员、门店管理员、服务员角色，防止越权访问。

部署需要服务器、域名、数据库，配置 PHP 运行环境，导入数据库文件，对接小程序以及微信支付宝支付、云打印接口。部署完成后总部维护基础菜品库，分配门店账号，门店完善菜品素材与业务参数，测试下单、支付、小票打印，提交各平台审核即可上线。

开源使用务必阅读开源协议，区分学习使用和商用授权。上线前做好安全加固，防护 SQL 注入、接口越权，校验支付回调，保障订单与资金安全。该方案适合连锁餐饮企业、本地餐饮服务商私有化部署，自主掌控业务数据，灵活迭代功能。
